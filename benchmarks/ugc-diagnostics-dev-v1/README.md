# UGC Python 工具链诊断开发任务集 v1

本目录是公开、合成、已见的开发任务集，服务于本机 Python 地图导出工具的诊断与优化。
不是网易业务代码，不包含蛋仔编辑器，不运行游戏引擎；不能据此声称渲染、GPU、物理性能或玩法体验提升。
其中三个实现有人为设置的资源使用缺陷，一个实现没有预设的优化需要。所有实现起始时都应通过公开功能测试。
这是性能诊断任务，不能把“原测试通过”误写成“无需诊断”，也不能要求每道题必须产生修改。

## 范围与输入输出

每个 `case-*/source/` 是单独的目标仓库内容。统一 API 是：

```python
map_exporter.export_map(objects, resources)
```

`objects` 为字典列表，每项包含 `id`、`resource_id`；`resources` 为字典列表，每项包含可哈希的 `id`、`path`。
返回按对象原顺序排列的字典列表，每项只有 `object_id`、`resource_path`。
重复资源 ID 必须使用第一项，未引用资源可以忽略，空对象列表返回空列表，缺失被引用资源抛出 `ValueError`。
不得修改输入，包括异常路径。额外 metadata 不参与输出。注册探针使用整数 ID，公开测试也覆盖字符串；API 支持可哈希的资源 ID，输出保持对象 ID。
当前仅允许修改已有的 `map_exporter.py`，公开测试和其他文件不在可修改范围内。

## 维护方资格信息

本节用于维护方审查任务覆盖，不输入 Agent 的任务上下文。

| 项目 | 预设状态 | 希望诊断区分的现象 |
| --- | --- | --- |
| case-01 | 人为 CPU 缺陷 | 导出过程中反复线性查找资源，工作量随对象数和资源数共同增加 |
| case-02 | 人为 CPU 缺陷 | 每个对象重复构建相同资源关系，表面症状与上一项相似 |
| case-03 | 人为内存缺陷 | 中间 staging 为每个对象保留独立资源列表，最终输出不需要这些重复列表 |
| case-04 | 健康实现 | 一次索引与顺序输出；允许正确得出“当前证据不足以支持修改” |

没有提供参考补丁。首项重复资源语义、输入顺序和缺失处理是所有任务共同的行为约束。
健康实现只作为独立任务提供，不得在其他任务的上下文中给 Agent 阅读，以免暴露解决线索。
不使用 `sleep`、固定延迟或虚构数据制造性能提升。

## Agent 可见性

- 每次只准备当前 case 的 `source/`，其中只有源码、API 说明和公开小测试。
- 顶层本 README、`manifest.json`、`qualification.py` 属于可信开发/任务准备侧，不挂载到目标仓库。
- 不把另一 case、维护方根因说明、已诊断结论或历史补丁加入当前 Agent 上下文。
- `manifest.json` 使用中性 case ID，仅记录接口、可见文件及哈希，没有根因或参考补丁字段。

## 功能资格检查

从工作台根目录执行：

```bash
.venv/bin/python benchmarks/ugc-diagnostics-dev-v1/qualification.py
.venv/bin/python -m unittest discover -s tests -p 'test_ugc_workloads.py' -v
```

`qualification.py` 只加载固定四个、源码哈希匹配的已审查夹具，不接收任意仓库或候选路径；修改后的候选仍必须走工作台的受限执行器。
该检查仅使用很小的输入验证顺序、首项语义、缺失、空输入和输入不变；输出明确标记 `performance_measured: false`、`real_model_calls: 0`。
每个目标仓库中的 `tests/test_export.py` 是公开测试，可在其自身目录运行 `python -m unittest discover -s tests -v`。

## 性能与结果口径

诊断和最终测量由工作台注册的可信工具完成；本目录不接收模型自写计时代码、任意 Shell 或运行命令。
CPU 时间与内存峰值分别测量，profiler/tracemalloc 的观察开销不能计入未经说明的产品收益。
应保留基线与候选原始结果、输入规模、种子、运行环境和失败；功能约束通过后才能比较性能。
公开小测试通过、夹具资格通过、工具执行器通过和 Agent 真实任务完成分别报告。
该开发集没有独立验收题，也没有真实模型结果；重复运行不能算成不同 Bug 或泛化成功率。
未来独立评测需要新建未见任务和冻结评分协议，不将本目录改名为 holdout。
