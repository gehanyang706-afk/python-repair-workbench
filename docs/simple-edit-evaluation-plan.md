# 简化编辑接口真实模型对照实验（待批准）

目标仅验证模型是否更容易形成合法候选，不能从两道旧任务推断广泛修复能力。任务均已用于历史开发或结果分析，属于回归任务，不是未见任务。

| 项目 | 任务 | 对照配置 |
| --- | --- | --- |
| boltons | `bits-empty-conversion` | `v2`、`simple_edit` |
| more-itertools | `bucket-falsey-validator` | `v2`、`simple_edit` |

两组使用同一 `qwen-plus` 服务和已有模型参数、同一固定数据集、同一本地镜像、同一任务文本与批准路径；每次运行最多 12 次模型调用、3 次候选、240 秒任务期限、30 秒单次测试。顺序固定为每题先 `v2` 后 `simple_edit`。不修改测试、独立验收、任务文本、候选评分或两配置以外的 Agent 策略。`simple_edit` 只改编辑工具与对应说明；引用解析及错误恢复是该接口的一部分，故结论归因于接口包，不能拆分声称每一项单独有效。

四次任务运行合计最多 48 次模型调用。按每次输入 8k–32k、输出 1k–4,096 token 规划，预计总输入约 12.8 万–153.6 万、总输出约 1.6 万–19.66 万 token。按阿里云百炼北京区域 `qwen-plus` 在单次输入不超过 128k 时的公开原价，非思考输入 ¥0.8/百万 token、输出 ¥2/百万 token；若输出按思考价格 ¥8/百万 token 估算，情景费用约 ¥0.13–¥2.80。实际价格、缓存、优惠及是否进入更高输入档位以供应商账单为准，这不是硬费用上限。价格来源：<https://help.aliyun.com/zh/model-studio/qwen-plus>，查验日期 2026-10-12。

不调用模型的任务资格验证已完成：两题均为 `qualified`，模型调用均为 0，记录分别保存在忽略 Git 的 `runtime/simple-edit-qualification-boltons-20261012/` 和 `runtime/simple-edit-qualification-more-itertools-20261012/`。运行时逐题检查模型调用数和 token 用量；发生认证或欠费、单次输入超过 128k、异常高频调用、环境资格失败时停止后续任务并保留证据，不自动扩大任务或重跑。未经批准不启动真实模型调用。

报告逐题列出：Schema 拒绝、提交请求、预检拒绝、物化候选、Docker 验证、语法通过、公开测试通过、独立验收通过，以及首个有效候选前调用数、实际输入/输出 token、耗时和失败原因。历史 v2 结果只作为背景，不直接与本次不同采样构成因果比较；正式比较只使用本计划内的成对运行。
